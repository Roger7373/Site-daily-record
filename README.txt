# Site Daily Record — PWA

这是工地日勤表第一版的 PWA 包。

## 文件
- index.html：App 主页面
- manifest.webmanifest：手机安装信息
- sw.js：离线缓存
- icons/：App 图标

## 重要
PWA 通常需要通过 HTTPS 网站安装，不能只从手机本地打开 HTML 文件后直接安装。

## Android Chrome 安装
1. 打开部署后的 HTTPS 地址。
2. Chrome 菜单 ⋮。
3. 选择「安装应用」或「添加到主屏幕」。
4. 名称：Site Daily Record。

## 当前功能
Project / Date / Worker / Attendance / Work Done / OT / Remarks / Daily Wage / Monthly Salary / Save / Print Report。
